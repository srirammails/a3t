A3T describes agents and processes in the [CNCF Serverless Workflow](https://github.com/serverlessworkflow/specification) DSL: an open, vendor-neutral workflow language written in YAML. The project, still in the CNCF, now goes by the [Open Workflow Specification](https://open-workflow-specification.org/).

Below is the whole 1.0 schema as one tree. Click **+** on any key to see what it is for and an example, and to open the layer inside it. New to YAML? Read [How to Read and Write YAML](../how-to-read-and-write-yaml/) first.

## Three rules that hold everywhere

1. **Data flows down the list.** Each task's output is the next task's input. Inside a task, `.` is that input.
2. **`${ }` is jq.** Anything inside it is a [jq](https://jqlang.github.io/jq/) expression evaluated at run time. Quote it when it contains `: `.
3. **A task is a one-key map.** In `do`, `try`, `fork.branches` and `switch`, each list item is `- name:` and the task sits under it.

## How A3T runs it

A3T runs these workflows on a runtime written in Rust, and adds two kinds of `call`: `call: adb` runs [AQL](https://github.com/srirammails/AQL) queries against agent memory, and `call: a3t:agent` runs an LLM agent, with tools and memory, as a single task. Everything in the tree above works as written.
