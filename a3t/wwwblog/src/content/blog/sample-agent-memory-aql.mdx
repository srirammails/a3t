Agents that run for weeks need to remember what they saw, what they did and what worked.
A3T keeps that memory in a store you can query, govern and forget from.

## Three kinds of memory

1. **Episodic**: what happened in each run.
2. **Semantic**: facts and entities, linked into a knowledge graph.
3. **Procedural**: the steps that worked, so the agent can reuse them.

## Querying it

AQL (Agent Query Language) reads like SQL with graph steps. The docs cover the full syntax.
